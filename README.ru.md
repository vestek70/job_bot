# Job Bot — поиск вакансий и резюме под каждую вакансию (Бразилия, IT/dev)

**Полуавтоматический** инструмент поиска работы: находит вакансии в 7 источниках,
генерирует резюме, заточенное под конкретную вакансию, и — только после твоего
подтверждения — отправляет по email. Локальная панель в браузере, на португальском
или русском.

> **Ничего не отправляется без твоего клика и подтверждения.** Никакого
> автологина на площадках, никакого скрапинга, никаких выдуманных фактов в
> резюме. См. [Принципы безопасности](#принципы-безопасности).

---

## Что он делает

1. **Ищет вакансии** в 7 публичных источниках (Adzuna, Remotive, Arbeitnow,
   RemoteOK, Jobicy, The Muse, Jooble) — без логина, только публичные API.
2. **Фильтрует** лишнее: не разработка, выше твоего уровня, офис в другом
   городе или «удалёнка», привязанная к другой стране.
3. **Генерирует резюме под вакансию**, которую ТЫ выбрал, через ИИ (DeepSeek) —
   в PDF и Markdown, с форматированием под ATS.
4. **Ведёт учёт откликов**: избранное (★), архив вакансий, на которые уже
   откликнулся, и удаление неподходящих.
5. **Отправляет по email** (опционально) вакансии с контактным адресом — всегда
   с явным подтверждением.

## Резюме адаптируется, а не выдумывается

Это ядро проекта. Бот читает `base_resume.md` (твои реальные факты) и описание
вакансии, и переписывает резюме под неё:

- **Зеркалит формулировки вакансии**, чтобы пройти отбор ATS/ИИ: если в вакансии
  «Postgres», а у тебя «PostgreSQL» — выровняет написание; просят «REST APIs» —
  использует этот термин. Но **только для того, что у тебя реально есть**.
- **Меняет угол подачи**: бэкенд-вакансия → на первый план база/API/безопасность;
  фронтенд → React/JavaScript/PWA.
- **Выносит релевантные ключевые слова наверх** (резюме + навыки) — там ATS даёт
  больший вес.
- **Никогда не выдумывает** технологию, компанию, должность или сертификат,
  которых нет в твоём `base_resume.md`. Если вакансия просит то, чего у тебя
  нет — бот не напишет, что оно есть.

## Установка

Требования: Python 3.10+.

```bash
git clone https://github.com/vestek70/job_bot.git
cd job_bot
pip install -r requirements.txt
```

### 1. Создай своё базовое резюме

```bash
copy base_resume.example.md base_resume.md    # Linux/Mac: cp
```

Открой `base_resume.md` и заполни **своими** реальными данными. Этот файл —
единственный источник фактов для бота: чем конкретнее (цифры, результаты,
технологии), тем лучше результат. Файл в `.gitignore` — личные данные не
попадут в репозиторий.

### 2. Настрой ключи

Создай файл `.env` в корне проекта:

```ini
# Поиск вакансий (обязательно) — регистрация бесплатная
ADZUNA_APP_ID=твой_app_id
ADZUNA_APP_KEY=твой_app_key

# Генерация резюме через ИИ (обязательно для резюме)
DEEPSEEK_API_KEY=твой_ключ

# Дополнительный источник вакансий (опционально, бесплатно)
JOOBLE_API_KEY=твой_ключ

# Отправка по email (опционально)
GMAIL_ADDRESS=твой-email@gmail.com
GMAIL_APP_PASSWORD=пароль_приложения

# Настройки (опционально)
HOME_CITY=Florianópolis
SEARCH_KEYWORDS=desenvolvedor fullstack
UI_LANG=ru          # язык панели: pt или ru
```

Где взять ключи (у всех есть бесплатный тариф):

| Ключ | Где | Обязателен? |
|---|---|---|
| `ADZUNA_APP_ID` / `ADZUNA_APP_KEY` | https://developer.adzuna.com/signup | Да (поиск) |
| `DEEPSEEK_API_KEY` | https://platform.deepseek.com/api_keys | Да (резюме) |
| `JOOBLE_API_KEY` | https://jooble.org/api/about | Нет |
| `GMAIL_APP_PASSWORD` | https://myaccount.google.com/apppasswords | Нет (только отправка) |

> **Пароль приложения Gmail** — это отдельный пароль для приложений, а не твой
> обычный. Нужна включённая двухфакторная аутентификация. `.env` в
> `.gitignore` — никогда не коммить ключи.

## Использование

```bash
python app.py
```

Открой `http://127.0.0.1:5000` в браузере. Всё делается там:

- **🔍 Запустить поиск** — ищет по 7 источникам (можно вписать ключевые слова и
  отметить «с senior» / «любая локация»).
- **Создать резюме** — генерирует резюме под конкретную вакансию (~30 сек).
- **Открыть PDF** — посмотреть результат.
- **★** — в избранное (всплывает наверх; фильтр «Только избранное» вверху).
- **Отметить как отправлено** — вакансия уходит в **📁 Архив** (для вакансий,
  на которые откликнулся на сайте сам).
- **✕ Удалить** — исчезает из списка и не вернётся даже после нового поиска.
- **Отправить выбранные (e-mail)** — только для вакансий с контактным email;
  спросит подтверждение перед реальной отправкой.
- **PT / RU** (правый верхний угол) — переключение языка панели.

### Вставить вакансию вручную

Нашёл вакансию на Vagas.com, Gupy, Catho или LinkedIn? У этих площадок нет
публичного API, а скрапинг нарушил бы их правила. Поэтому:

1. Открой вакансию на сайте (в панели есть готовые кнопки поиска).
2. Скопируй текст вакансии.
3. Вставь в блок **«➕ Вставить вакансию вручную»** и нажми «Создать резюме».

Бот сделает резюме под неё, не трогая сайт — ты браузишь и копируешь, он только
адаптирует.

### Через терминал (опционально)

```bash
python main.py "desenvolvedor fullstack"        # только поиск, сохраняет в jobs_found.csv
python main.py "python" --include-senior        # включая senior-вакансии
python main.py "dev" --any-location             # без фильтра локации
python clean_applications.py --days 45 --apply  # чистка старых резюме
```

## Источники вакансий

| Источник | Покрытие | Ключ |
|---|---|---|
| **Adzuna** | Бразилия (3 прохода: ключевое слово, широкий поиск, локальное усиление) | Да |
| **Jooble** | Агрегатор, Бразилия | Да (бесплатно) |
| **Remotive** | Международная удалёнка | Нет |
| **Arbeitnow** | Международная удалёнка | Нет |
| **RemoteOK** | Международная удалёнка | Нет |
| **Jobicy** | Международная удалёнка | Нет |
| **The Muse** | Бразилия + удалёнка | Нет |

Дубли между источниками объединяются. `jobs_found.csv` **накапливается** между
запусками: уже виденные вакансии сохраняют историю и резюме, пропавшие из выдачи
помечаются «не в последнем поиске» и удаляются только через
`STALE_JOB_DROP_DAYS` дней (по умолчанию 45).

## Фильтры

Три фильтра работают последовательно (все настраиваются в `.env`):

1. **Релевантность** — оставляет только вакансии по разработке (`RELEVANCE_KEYWORDS`).
2. **Уровень** — отсеивает senior/lead/руководящие (отключить: `--include-senior`).
3. **Локация** — оставляет вакансии в твоём городе (`HOME_CITY`) **или**
   настоящую удалёнку. Гибрид в другом городе считается офисом и отсеивается;
   «удалёнка», привязанная к другой стране (напр. «Remote (Berlin)») — тоже.
   Отключить: `--any-location`.

## Принципы безопасности

Осознанные решения проекта — см. `SECURITY_REVIEW.md`:

- **Никакого логина и автоматизации на площадках.** Никакого Selenium с входом
  в LinkedIn/Gupy/Catho — это нарушает их правила.
- **Никакого скрапинга.** Только публичные официальные API. Для площадок без API
  бот открывает их поиск в браузере, либо ты вставляешь текст вакансии сам.
- **Ни одной отправки без подтверждения.** Режима «откликнуться на всё
  автоматически» не существует.
- **Никаких выдумок в резюме.** Промпт прямо запрещает добавлять технологии,
  компании и опыт, которых нет в твоём базовом резюме.
- **Работает только локально** (`127.0.0.1`) — ничего не выставлено в интернет.
- **Данные остаются у тебя**: `.env`, `base_resume.md`, `jobs_found.csv` и
  `applications/` — всё в `.gitignore`.

## Известные ограничения

- Количество вакансий зависит от ниши. Строгие фильтры (junior/pleno + конкретный
  город) могут давать мало новых вакансий в день — это рынок, а не баг.
- У бразильских площадок (Vagas.com, Gupy, Catho, InfoJobs) нет публичного API,
  и они принципиально не скрапятся; используй ручную вставку вакансии.
- Качество резюме зависит от качества твоего `base_resume.md`.
  **Всегда проверяй PDF перед отправкой.**
